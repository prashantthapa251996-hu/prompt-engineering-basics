# Foundational Prompt Log

## Task 1: Text Summarization

### Prompt Input

Act as an Editor. Summarize the text below in exactly three bullet points.

Text: "Remote work has rapidly expanded, introducing both opportunities and obstacles for modern businesses..."

### ChatGPT Output

- Remote work has expanded rapidly across modern businesses.
- It creates new opportunities for flexibility, productivity, and broader talent access.
- It also introduces challenges that businesses must manage effectively.


## Task 2: Information Extraction

Extract the customer's name, email address, and order ID from the support request below.

- **Customer Name:** John Doe

## Task 4: Tone Editing

### Prompt Input

Act as an Editor. Rewrite the draft text below to sound like a professional, polite B2B email sent to a client.

Draft: "hey, sorry we are late on the report. it had bugs. we will send it tomorrow. thanks."

Dear [Client Name],

Apologies for the delay in providing the report. We identified and are addressing some issues that affected the report.

We expect to share the completed report with you tomorrow.

Best regards,  
Prashant


## Task 5: Constraint-Driven Output

### Prompt Input

Sentence: "Our customer success managers are available 24 hours a day to guide new users and resolve technical account disputes."

### ChatGPT Output

Customer success managers are available 24/7 to guide new users and resolve technical account disputes.
