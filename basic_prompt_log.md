# Foundational Prompt Log

## Task 1: Text Summarization

### Prompt Input

```text
Summarize the text below in exactly three bullet points.

Text: "Remote work has rapidly expanded, introducing both opportunities and obstacles for modern businesses..."
```

### ChatGPT Output

- Remote work has expanded rapidly across modern businesses.
- It creates opportunities for flexibility and new ways of working.
- It also introduces challenges that businesses need to manage effectively.

## Task 4: Tone Editing

### Prompt Input


Thank you for your patience and understanding.
